# IT1214-Student-Grade-System

## Description
A simple Java console application to manage student grades. This system takes student ID, name, and marks as input and displays the grade and pass/fail status.

## Features
- Add student details
- Calculate grade based on marks
- Display Pass/Fail status

## Grading Scheme
| Marks Range | Grade |
| --- | --- |
| 75 - 100 | A |
| 65 - 74 | B |
| 55 - 64 | C |
| 35 - 54 | S |
| 0 - 34 | F |

## How to Run
1. Compile: `javac src/*.java`
2. Run: `java -cp src Main`
